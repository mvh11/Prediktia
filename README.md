# Prediktia ⚽📊

Sistema web de análisis estadístico deportivo enfocado en generación de value bets y combinadas inteligentes (ACCA).

## 🌐 Demo Online

Frontend (Vercel):
https://prediktia.vercel.app

Backend API (Render):
https://prediktia-backend.onrender.com/docs

---

# 📌 Descripción

Prediktia es una plataforma web desarrollada como proyecto académico, orientada al análisis de partidos de fútbol mediante estadísticas y probabilidades.

El sistema permite:

* Visualizar partidos disponibles
* Detectar value bets
* Generar combinadas ACCA según nivel de riesgo
* Guardar historial de combinadas generadas
* Consumir datos deportivos desde una API externa

---
